02 / BOUNDARY

Useful without pretending privacy does not exist.

RoJoiner can browse public game instances, resolve public account information, and create Roblox launch links. It cannot reveal private servers, hidden instance membership, or join permissions Roblox does not grant.

  • No Roblox password
  • No website-side session cookie
  • No remote search-history database
  • No privacy-setting bypass
